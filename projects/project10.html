Project 10: The Lone Wolf's Shadows

A local multi-agent AI coding assistant packaged as a Tauri desktop app. A prompt is routed to the right specialist agent, which pulls context from your project files and returns an answer — plus a before/after diff when code changes. Cloud models are tried first, with automatic fallback to a local Ollama model.

Key Features

  • 7 agents: coding, debugging, security, design, planning, research, vision
  • Keyword + LLM-fallback router with a persistent result cache
  • coding → reviewer → security pipeline for review prompts
  • Code execution sandbox (Python / JS / TS) with a 3-attempt auto-fix loop
  • Research agent: plan, search, scrape top results, synthesise a report
  • Filesystem and memory MCP servers registered at startup
  • Hybrid mode: cloud first, transparent local fallback, model badge on every reply
  • Dark glass-morphism UI with streaming chat, diff modal and admin dashboard
