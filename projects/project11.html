Project 11: AniTrack

An anime tracking application built with Symfony 7.4: a JSON REST API secured with JWT, and a server-rendered Twig front-end on top. Users browse anime by genre, write reviews and manage a watchlist with personal stats.

Key Features

  • REST API for anime, genres, reviews and watchlist (full CRUD)
  • JWT authentication: register, login, view and update your profile
  • Watchlist with status updates and personal statistics
  • Reviews per anime, plus a “my reviews” endpoint
  • Paginated lists (KnpPaginator) and CORS support
  • Central API exception listener for consistent JSON errors
  • Twig web pages: home, anime, auth, profile and watchlist
  • Docker Compose setup and Doctrine migrations + fixtures
