Project 12: Floppy Tilt Bird

A Flappy Bird-style game for phones where you steer by tilting the device. Built in vanilla JavaScript with ES modules, rendered on a full-screen canvas, and installable as an offline-capable Progressive Web App.

Key Features

  • Tilt steering through the DeviceOrientation API
  • iOS 13+ motion-permission handling
  • Keyboard-simulated tilt so it also plays on desktop
  • Full-screen canvas that resizes to the device
  • Separate Ball, Pipe and SensorManager modules
  • Service worker + manifest: installable and works offline
