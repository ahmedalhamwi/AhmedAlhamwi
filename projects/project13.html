Project 13: GeoCache PWA

A Progressive Web App that helps you find geocaches using real-time GPS, the phone's compass, and an interactive radar. Distances are calculated with the Haversine formula and a cache is found automatically once you are within 5 metres.

Key Features

  • Continuous GPS tracking with watchPosition (high accuracy)
  • Compass heading via the deviceorientation event
  • Interactive radar visualisation of nearby caches
  • Haversine distance calculation
  • Automatic cache discovery within 5 metres
  • Installable PWA with offline caching and responsive layout
