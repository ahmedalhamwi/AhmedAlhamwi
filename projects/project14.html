Project 14: Escape Room – Multi-Room Vault

A browser escape room with six short puzzles spread across separate rooms. Each room has to be solved in order to escape. Built as a single-page app with a neon sci-fi look and installable as a PWA.

  • Countdown timer and room tabs
  • Animated neon UI with scan-line and glow effects
  • Responsive layout for phone and desktop
  • Service worker + manifest for home-screen install
