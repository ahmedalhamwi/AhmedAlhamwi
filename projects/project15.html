Project 15: Snake Game

A classic Snake game on HTML5 Canvas with four game modes and a saved high score. The code is split into a game engine, renderer, input manager and UI manager, and it plays with arrow keys, swipes or on-screen buttons.

Key Features

  • Arrow keys, swipe gestures and on-screen buttons for mobile
