Project 18: SDG Dashboard – Abyss Chaos Group

An interactive web application for tracking and visualising the UN Sustainable Development Goals, built as a team for the Dashboard project. Each SDG theme gets its own page with KPI cards and charts, fed by a MySQL database and external APIs such as the World Bank and Open-Meteo.

Key Features

  • Overview page and a detail page per SDG
  • Themed pages: no poverty, good health, clean energy, climate action, life below water, life on land
  • KPI cards and charts (Chart.js, ECharts, Recharts)
  • Country data from the World Bank API and weather from Open-Meteo
  • Accounts: register, login, profile, change and reset password
  • Admin page for user management; contact and support pages
