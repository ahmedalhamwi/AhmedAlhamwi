Project 7: Alfa Ware GameShop

A production-style rebuild of the “Review Your Experience” game shop (originally PHP + MySQL + Bootstrap) in Next.js 16, React 19 and TypeScript strict — with real checkout flows on a self-hosted payment server, an admin panel, and a full CI/CD pipeline.

Key Features

  • Game catalogue with categories, sale prices and a “New” badge
  • Cart, checkout and order history
  • Payments via self-hosted Hyperswitch (test mode): cards, Google Pay, refunds
  • Customers request refunds; admins issue full or partial refunds
  • Accounts with sign-up, login and password reset (local Mailpit inbox)
  • Admin: orders, games & sales, review moderation, user roles & bans
  • Guard rails: you can't demote or ban yourself; the shop always keeps one admin
  • Liquid-glass UI in the original's navy and sky-blue colours
