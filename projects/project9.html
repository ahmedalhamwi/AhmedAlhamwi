Project 9: The Wolf Monarch AI

A free, self-learning AI agent built as a custom distribution of the open-source Goose agent, with a Hermes-inspired skill-learning layer on top. It runs on free cloud models or fully offline through Ollama. V2 of my earlier Lone Wolf's Shadows project.

Key Features

  • Custom Goose distribution, pinned as a git submodule with minimal patches
  • Skill-learner MCP extension — the agent saves and reuses learned skills
  • 11 recipes: code review, debugging, adding tests, dependency upgrades and more
  • Sub-agent spawning for parallel tasks
  • Runs on OpenRouter's free tier, or fully local with Ollama (qwen3:8b), network unplugged
  • Dark wolf-monarch branding and theme
  • Release-hygiene gate and defect register as part of the build process
  • CI build workflow on GitHub Actions
